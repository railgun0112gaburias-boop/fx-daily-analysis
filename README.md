# FX毎朝5時間足テクニカル分析

分析対象は **ZAR/JPY：みんなのFX**、**USD/JPY：GMOクリック証券**です。
取引口座には接続せず、建玉・純資産・維持率・売買量・強制ロスカット水準は取得・推測しません。

## データ取得元と時間区切り

2026年11月の取得停止への対応として、Dukascopyから **GMOコイン公式FX公開APIのBID OHLC**へ変更しました。
GMOコインは市場データの参照元です。みんなのFXおよびGMOクリック証券の口座・配信価格とは別です。
Ask、各社のスプレッド・スワップ・約定価格は取得しません。

- 公式仕様：<https://api.coin.z.com/fxdocs/>
- 公開エンドポイント：`https://forex-api.coin.z.com/public/v1/klines`
- 対象シンボル：`ZAR_JPY`、`USD_JPY`。認証キーは不要です。
- 過去のDukascopy系列と新しい系列は接続せず、毎回すべての指標を同一取得元から再計算します。過去レポートとの価格・指標差が生じます。
- 403はアクセス拒否として記録します。429、一時的な5xx、通信障害のみ上限3回で再試行します。

| 時間足 | 取得・集計方法 | 標準取得期間 |
|---|---|---|
| 15分 | 公式15分足、UTC 00/15/30/45分 | 15日 |
| 1時間 | 公式1時間足、UTC毎正時 | 45日 |
| 4時間 | 公式4時間足、UTC 00/04/08/12/16/20時を全行で検証 | 100日 |
| 日足 | 検証済み4時間足をUTC 00時で集計 | 400日前の週初から |
| 週足 | UTC日足を月曜00時UTCで集計 | 同上 |

APIの短期足取得用日付は **JST 06時**に切り替わります。取得キーをこの仕様に合わせます。
一方、分析の日足はUTC区切りを維持するため、取得元のJST 06時区切りの既成日足・週足は使いません。
実在するOHLCのみを集計し、休場日の価格を補間・捏造しません。国内業者のチャートとは価格・時間区切りが異なる場合があります。

## 毎朝の実行と更新状態

- GitHub Actionsを毎朝 **07:07（Asia/Tokyo）**に予定します。GitHub側の起動遅延はあり得ます。
- ソース・テスト・依存定義・ワークフロー変更時にも全期間の分析を実行します。
- `main`の実行だけがレポートを公開します。作業ブランチの検証から`main`へ書き込みません。
- `workflow_dispatch`の`quick_check`は短期の接続検証です。本番レポートとして公開しません。
- 通常出力は `reports/latest.json`、`reports/latest.md`、`reports/status.json` と注釈付きSVG・PNG各最大10枚です。
- 足終了後2分の確認猶予を置き、未確定足を除外します。40本未満は「判定不可」です。
- 判定基準時刻から算出した直近の確定足時刻に達していなければ`stale`とし、現在の分析・画像を公開しません。週明けも、新しい確定足が揃うまで一部の時間足が「未更新/判定不可」になる場合があります。
- 取得元が休場を報告した場合は`market_closed`、メンテナンス中は`unavailable`とします。

取得に失敗しても、**当日の失敗状態をGitHubに保存**します。解析前の失敗、前回のJSONの残留、今回のRun ID・生成日時の不一致も検出します。
旧画像・不一致画像は削除し、過去の成功レポートを最新として残しません。失敗レポートの保存に成功しても、Actionsの失敗は成功扱いに変更しません。
チェックアウト・GitHubへの書き込み自体が失敗した場合や実行がキャンセルされた場合は保存できないため、生成日時とActions履歴も確認してください。

`generatedUTC`はJSONと画像の共通生成日時、`requestedCutoffUTC`は確定足選別の基準日時です。
各通貨の`fetch.fetchedUTC`・`requestLog`で実際の取得日時、各足の`latestCloseUTC`で確定足の終了日時を確認できます。
`reports/status.json`は実行ID、成功・失敗区分、利用可能時間足数、画像数、エラーを記録します。

## 指標と注釈付きチャート

- 表示用に、日時照合済みのSVGからPNG（2360×1240）も生成します。Markdownの埋込はPNGを使用し、元のSVGリンクも残します。
- `pngCharts`にPNGのパス、`chartArtifacts`にSVG/PNGのSHA-256、共通生成日時・確定足日時・画像サイズを保存します。古いSVGからPNGを作り直して最新と扱うことはありません。
- 日本語文字を保持するため、Actionsは`fonts-noto-cjk`をインストールします。手元でも同パッケージが必要です。PNG生成失敗時は失敗状態を記録し、SVGへのリンクだけを残します。

- 左右2本で確定したスイング高安値、直近2組の高安値によるダウ判定、支持抵抗候補、RSI14、MACD12/26/9を計算します。
- 両通貨の15分・1時間・4時間・日足・週足を `reports/charts/<symbol>_<timeframe>.svg` に生成します。
- 各SVGに確定スイングH/L、S1〜S3、R1〜R3、確定足終値、生成日時、足の確定日時、参照元と分析対象口座を表示します。実測候補がない項目は「候補なし」です。
- ZAR/JPYは「ショート開始観察」「ショート解除①観察」「ショート解除②観察」、USD/JPYは「戻り売り/上抜け観察」「押し目/下抜け観察」を区別します。
- **画像の観察候補は未確認の発注条件です。** 売買指示や勝率・期待値の保証ではありません。
- SVGの埋込メタデータにある通貨・時間足・生成日時・確定足日時をJSONと照合してから、Markdownに4時間足画像と5時間足リンクを掲載します。
- 取得不能・古い足・休場・確定足不足・画像不一致の時間足については、旧画像を流用しません。

## 手元での実行

Node.js 20以降（GitHub Actionsでは22）を使用します。

```sh
npm ci --no-audit --no-fund
npm test
npm run analyze
```

短期接続検証は `FX_QUICK_CHECK=1 npm run analyze` です。週足などの指標計算には期間が足りず、本番の分析結果とは区別します。
`src/finalize-run.mjs`はActionsの実行開始日時・Run ID・分析結果を受け取り、今回の出力を検証して公開用ファイルを整えます。

GitHub側の処理とChatGPTの定時報告は別です。このリポジトリの成功だけでChatGPT側の定時配信まで検証済みとは扱いません。
公開リポジトリに口座情報、取引履歴、認証キー、秘密情報を保存しないでください。
